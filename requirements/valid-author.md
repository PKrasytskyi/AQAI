# Valid Authentication Requirements

## Objective
Verify that a user can authenticate with valid credentials and reach the authenticated area.

## Functional Requirements
- User can open home page
- User can click the authentication entry point link
- User redirected to login page
- User can login with valid credentials
- User redirected to the authenticated area

## Assertion Requirements
- Login page is opened
- Username and password input field and login button are present
- User logged with valid credentials and redirected to the authenticated area
- Authenticated welcome message is visible.

## UI Expectations
- Login page route matches the project login route.
- Authenticated area route matches the project authenticated route.
- Authenticated welcome message matches the project profile expectation.

## Non-Functional Requirements


## Out Of Scope
- Checkout flow
- Payment flow
- Account registration
- Profile management
