# Rules
- Generate exactly one atomic test spec for one canonical test case.
- Use only supplied public page-object API.
- Do not reference locators, WebDriver, Selenium internals, waits, or page internals.
- Build required state inside the same test.
- Use credentials or scenario data only when required by the test case.
- Do not invent page methods.
- Invalid: Java bodies, fallback branches, comments, or cross-test dependency.
